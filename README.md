#  iOS По-взрослому

## Структура папок

__Resources__ - ассеты, шрифты

__AppDelegate__ - старт приложения, координатор, фабрика, корневая навигация (таббар)

__Scenes__ - собственно сами экраны, каждый экран располагается в своей отдельной папке

__Components__ - общие компоненты, использующиеся на разных экранах, каждая компонента располагается в своей отдельной папке

__Configuration__ - конфиги для приложения или других библиотек

## Ресурсы

__Изображения__ - сохраняются из фигмы в pdf, если это вектор. И только если картинка не вектор (фотография), то она сохраняется как png в трех размерах. Для вектора не забывать ставить галочку "Preserve Vector Data". Доступ к изображениям из кода через `UIImage(resource: .picture)` или сокрашенно `.picture`.

__Цвета__ - уже заведены по таблице цветов макета, в проекте используются только они через `UIColor(resource: .blue80)` или сокращенно `.blue80`. Если нужного цвета нет, уведомить дизайнера.

__Шрифты__ - уже заведены по таблице шрифтов, в проекте используются только они через структуру Font. Так как в проекте все шрифты с леттерингом, то там где это критично, например кнопки, или заголовки, помещенные в заданную ширину, используйте: 
```
    someObject.attributedText = Font.heading1.compose("Your text", color: .black)
```
цвет опциональный, по дефолту черный.
    
## Сцены

Так как в проекте много экранов и сейчас не всегда есть возможность разместить его там где он должен быть, создана DummyScene, к которой можно подключить ваш экран. Для этого нужно:
- создать в Factory метод, собирающий ваш экран
- создать в AppCoordinator метод, открывающий ваш экран
- прописать в SceneType новый кейс, идентифицирующий ваш экран и задать ему имя
- прописать в статическом свойстве models стрктуры SceneModel новую строку, которая будет отображаться в DummyScene
- прописать в DummyViewController в методе route переход на ваш экран

В качестве примера можно использовать как сделано с экраном TextFieldsScene
