#  iOS По-взрослому

## Структура папок

Resources - ассеты, шрифты
AppDelegate - старт приложения, координатор, фабрика, корневая навигация (таббар)
Scenes - собственно сами экраны, каждый экран располагается в своей отдельной папке
Configuration - конфиги для приложения или других библиотек

## Ресурсы

__Изображения__ - сохраняются из фигмы в pdf, если это вектор. И только если картинка не вектор (фотография), то она сохраняется как png в трех размерах. Для вектора не забывать ставить галочку "Preserve Vector Data".
Доступ к изображениям из кода через UIImage(resource: .picture)

__Цвета__ - уже заведены по таблице цветов макета, в проекте используются только они через UIColor(resource: .blue80)
Если нужного цвета нет, уведомить дизайнера.

__Шрифты__ - уже заведены по таблице шрифтов, в проекте используются только они через перечисление Font.
